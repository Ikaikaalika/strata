# Raw benchmark evidence

Every JSON file in this directory is an immutable raw record. Do not edit,
reformat, or rename a recorded result; add a new file instead.

Files recorded before 2026-10-09 were produced while the project was named
Strata. They keep their original file names and identifiers, for example:

| Recorded identifier | Current identifier |
|---|---|
| `strata-paged-mlx-lab` | `lokahi-paged-mlx-lab` |
| `strata-resident-mlx-route-comparison` | `lokahi-resident-mlx-route-comparison` |
| `strata-ane-*` | `lokahi-ane-*` |
| `apple_m1_strata_*.json` | new results use `apple_m1_lokahi_*.json` |

Tools that read raw records accept both forms.
